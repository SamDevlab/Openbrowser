# M8.1 expanded deterministic compatibility corpus

This follow-up grows the real-browser differential corpus from 3 to 10 local scenarios while keeping the same Openbrowser-vs-Chromium execution boundary.

The corpus now covers:

1. basic navigation;
2. HTTP redirect chains;
3. JavaScript DOM mutation plus localStorage;
4. fragment/hash navigation;
5. History API state replacement;
6. same-origin JSON XHR and DOM projection;
7. external same-origin script loading;
8. JavaScript cookie visibility;
9. localStorage and sessionStorage lifecycle semantics;
10. core DOM creation and mutation APIs.

The fixture observation bridge now reports deterministic custom events, localStorage, sessionStorage and normalized document cookies in addition to final URL, title and marked DOM content.

All scenarios remain local, versioned and reproducible. No live third-party site is used as an acceptance oracle. The corpus intentionally stays small enough for PR CI while covering multiple web-platform surfaces that are historically easy to regress through browser policy, storage partitioning, navigation or request handling changes.

This is still not a replacement for Web Platform Tests. M8.2 introduces a separate pinned WPT smoke layer.
