# M8.1 — Real-browser differential execution

M8.1 turns the M8 protocol/harness into a real browser-to-browser compatibility gate.

## Reference pair

The Windows differential job executes the same deterministic local fixtures against:

- a native Openbrowser build using CEF `151.3.17+gf059e67+chromium-151.0.7922.138`;
- Chrome for Testing headless shell `151.0.7922.138` (`win64`, revision `1654411`).

The Chromium reference archive is pinned by exact version and repository SHA-256. CI verifies the archive before extraction and also checks the executable-reported version.

## Observation bridge

The production browser does not gain a DOM-inspection backdoor for this test. Instead, compatibility fixtures load `compatibility-observe.js`, which publishes a bounded test observation to a per-run localhost collector protected by an unguessable token.

The common observations are:

- canonical final URL;
- document title;
- deterministic DOM marker/text values;
- stable fixture events;
- localStorage contents.

The harness still independently records fixture HTTP requests and performs normalization and field-by-field comparison.

## Current deterministic scenarios

1. basic navigation and DOM observation;
2. local redirect-chain resolution;
3. JavaScript DOM mutation plus localStorage persistence.

A first real-browser CI execution produced `3 passed, 0 incompatible, 0 runner failures`.

## Lifecycle requirements

The Openbrowser runner remains stricter than a compatibility-only observation:

- the real native browser must launch successfully;
- the fixture must be observed;
- graceful close must be accepted;
- the process must exit with code `0`;
- persisted session state must report `clean_shutdown: true`.

A browser crash, timeout, missing observation, checksum mismatch or bad shutdown is a runner failure and cannot become a compatibility pass.

## Artifacts

The `Web Compatibility Differential` workflow uploads:

- `real-browser-differential.json` — normalized scenario results and differences;
- `reference-metadata.json` — Openbrowser commit, CEF pin, Chromium reference version and downloaded archive SHA-256.

## Deliberate next steps

M8.1 does not claim full Web Platform Tests coverage, rendering reftests or a live-site corpus. Those are follow-up layers after the real-browser differential boundary is stable.
